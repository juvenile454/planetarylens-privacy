Summary

PlanetaryLens displays Earth observations, camera stills, timelapses and wildlife photos. It has no accounts, advertising, analytics or crash-reporting SDKs. We do not create usage profiles or run a user database.

The app does not request location or camera permission. Searches, saved sources and device location are not sent to providers. Visible previews can already contact image providers, including on the start screen. World layers contact public measurement services. Network requests still disclose connection data: each service technically receives the IP address, request time, requested resource and PlanetaryLens User-Agent and may log that data.

Permissions and purposes

  • Internet: used to load public images, observation feeds and, when a source-control URL is configured, a small HTTPS control file.

PlanetaryLens requests neither location, camera, storage nor media permissions, and it does not request background location.

Network services and transmitted data

Displaying previews in Discover and Catalog can connect to image providers as soon as a preview is visible. Opening a source loads its image; current camera images can refresh while visible. Clips and timelapses start only when you tap play. Switching to World loads the enabled measurement layers; switching them off, leaving World or putting the app in the background stops polling. An in-flight request can finish within its network timeout.

  • Media: U.S. Geological Survey (USGS NIMS/HIVIS and the Hawaiian, Alaska, Cascades and Yellowstone Volcano Observatories, including USGS Amazon S3 and volcview.wr.usgs.gov image delivery); PhenoCam Network / Northern Arizona University; GeoNet / Earth Sciences New Zealand; iNaturalist Open Data through Amazon S3. Provider attribution and source/rights links appear in every detail view.
  • World layers: USGS for earthquakes; NOAA NDBC and PacIOOS / University of Hawaiʻi for buoy measurements and wave models; NOAA Aviation Weather Center for wind; GitHub for the prepared NASA FIRMS fire feed; NOAA CO-OPS, USGS Water Services, PEGELONLINE / German Federal Waterways and Shipping Administration, Environment and Climate Change Canada, Environment Agency (England), and Hub’Eau / Eaufrance for water levels.

Fire data use a fixed public GitHub URL. The NASA preparation job receives no requests from your phone; its API key is never included in the app. The globe texture, borders and capitals are bundled locally and do not contact a map or tile service. Source locations identify the observation site, not your phone.

All connections use HTTPS. Services technically receive the IP address, request time, requested resource and User-Agent PlanetaryLens/0.9 (Android; direct provider media). These requests contain no advertising ID, installation ID, account ID, GPS position, search text or saved list. The selected resource can reveal which content you are viewing. The app does not intentionally set cookies or send browser cookies. PlanetaryLens has no advertising, account, analytics or crash-reporting SDK and does not sell data.

Logging by external providers

PlanetaryLens does not store this network metadata itself. The providers operate their own servers and may retain requests under their policies. PlanetaryLens cannot access or delete these logs and does not control their retention. GitHub describes deriving a general geographic region from IP addresses; PlanetaryLens itself does not calculate your location. More information: GitHub General Privacy Statement.

Local storage, retention and deletion

Saved sources are stored as catalog IDs in private app storage. Searches, map selections and the current screen are processed locally; Android may retain screen state to restore the app. Your primary device language is read locally: German selects German, every other language selects English. It is not sent as a user preference.

If a source-control URL is configured, the most recently downloaded manifest is stored locally. It contains source IDs, provider names and public notices, not user identifiers. It is replaced after a successful refresh. No source-control URL is configured in PlanetaryLens 0.9, so this file is not requested or stored.

App cloud backup and device-transfer backup are disabled. Images, video buffers and observation feeds are held in memory without a persistent media cache. Closing a view releases its media; Android manages final memory reclamation.

Remove saved items with the star or clear the saved list under About. To remove all local data, use Android Settings → Apps → PlanetaryLens → Storage → Clear data, or uninstall the app. This does not delete provider logs. There is no PlanetaryLens account or server-side PlanetaryLens user database.

Source controls

When a manifest URL is configured, the app requests a small HTTPS file on entering the foreground and about every 15 minutes while in the foreground. It can remove sources and show notices, without downloading executable code or adding sources. The host would receive the connection data described above. Offline, the last valid file would continue to apply; immediate removal on an offline device cannot be guaranteed. PlanetaryLens 0.9 does not configure this URL.

Viewing this policy inside the app works offline. Opening its public web version contacts GitHub Pages through your browser.

Secure delivery, abuse prevention, source controls and handling rights complaints serve our legitimate interests in operating a reliable and lawful service (Article 6(1)(f) GDPR). We do not use these data for advertising or profiling. Independent providers determine the legal bases for their own operations; their policies apply to their server logs and websites.

If you contact us by email, we receive your address, message and information you choose to attach. We use these to answer your request or handle a rights complaint. Contract-related requests rely on Article 6(1)(b), other support and complaints on Article 6(1)(f), and legally required records on Article 6(1)(c). Do not include unnecessary sensitive data. Correspondence is deleted after the request is resolved and no longer needed, unless an applicable retention duty or a legal dispute requires continued storage.

International processing

Direct requests can be processed outside your country, including the United States, Canada and New Zealand, by the providers and their infrastructure. This may involve different data-protection rules. This privacy page is hosted by GitHub, Inc. in the United States.

Your rights

Subject to the applicable legal conditions, you may request access, correction, erasure, restriction and portability of your personal data. You may object to processing based on legitimate interests and complain to a data-protection supervisory authority, particularly where you live or work. Contact our privacy address above. We do not need additional identifying information merely to create a record about you. For data controlled independently by a provider, its privacy contact can handle the request; we can help identify the relevant provider.

Children's privacy

PlanetaryLens is intended for a general audience interested in Earth observations and is not specifically directed at children. There is no account, advertising, user upload, chat or communication between users. If a minor uses the app, the same data handling described above applies; no age-related profiling takes place. We do not perform automated decisions with legal or similarly significant effects.

Provider pages and email links open an external app. That app and the destination service have their own privacy practices.

Changes

If data handling, permissions or network services change, this policy will be updated together with the app. The version above identifies the app release covered by the policy.

Kurzfassung

PlanetaryLens zeigt Erdbeobachtungen, Kameraeinzelbilder, Zeitraffer und Tierfotos. Es gibt keine Konten, Werbung, Analyse- oder Absturzbericht-SDKs. Wir erstellen keine Nutzungsprofile und betreiben keine Nutzerdatenbank.

Die App fordert keine Standort- oder Kameraberechtigung an. Suchtexte, Merkliste und Gerätestandort werden nicht an Betreiber gesendet. Sichtbare Vorschaubilder können bereits eine Verbindung zum Bildanbieter auslösen, auch auf der Startseite. Die Weltebenen kontaktieren öffentliche Messdienste. Beim Laden von Inhalten erhalten die ausliefernden Dienste dennoch technische Verbindungsdaten: IP-Adresse, Abrufzeit, angeforderte Ressource und PlanetaryLens-User-Agent, und können diese Angaben protokollieren.

Berechtigungen und Zwecke

  • Internet: Abruf öffentlicher Bilder, Messdaten und, sofern eine Quellen-Manifest-URL konfiguriert ist, einer kleinen HTTPS-Steuerdatei.

PlanetaryLens fordert keine Standort-, Kamera-, Speicher- oder Medienberechtigung und keine Hintergrundortung an.

Netzwerkdienste und übertragene Daten

Sichtbare Vorschaubilder in „Entdecken“ und „Katalog“ können bereits beim Anzeigen eine Verbindung zum Bildanbieter auslösen. Eine Quelldetailansicht lädt ihr Bild; aktuelle Kamerabilder können sich bei sichtbarer Ansicht aktualisieren. Clips und Zeitraffer starten erst nach Antippen der Wiedergabe. „Welt“ lädt die eingeschalteten Messebenen. Ausschalten einer Ebene, Verlassen von „Welt“ oder der Wechsel in den Hintergrund beendet das regelmäßige Nachladen. Ein laufender Abruf kann innerhalb seines Netzwerk-Zeitlimits noch zu Ende gehen.

  • Medien: U.S. Geological Survey (USGS NIMS/HIVIS sowie Hawaiian, Alaska, Cascades und Yellowstone Volcano Observatory, einschließlich USGS-Bildauslieferung über Amazon S3 und volcview.wr.usgs.gov); PhenoCam Network / Northern Arizona University; GeoNet / Earth Sciences New Zealand; iNaturalist Open Data über Amazon S3. Attribution sowie Quellen- und Lizenzlinks stehen in jeder Detailansicht.
  • Weltebenen: USGS für Beben; NOAA NDBC und PacIOOS / University of Hawaiʻi für Bojen und Wellenmodelle; NOAA Aviation Weather Center für Wind; GitHub für den aufbereiteten NASA-FIRMS-Feuerfeed; NOAA CO-OPS, USGS Water Services, PEGELONLINE / Wasserstraßen- und Schifffahrtsverwaltung des Bundes, Environment and Climate Change Canada, Environment Agency (England) und Hub’Eau / Eaufrance für Wasserpegel.

Der Feuerfeed nutzt eine feste öffentliche GitHub-URL. Der NASA-Datenjob erhält keine Anfragen vom Handy; sein API-Schlüssel ist nie Bestandteil der App. Erdtextur, Grenzen und Hauptstädte liegen lokal in der App und kontaktieren keinen Karten- oder Kacheldienst. Quellenkoordinaten bezeichnen Beobachtungsorte, nicht deinen Gerätestandort.

Alle Verbindungen nutzen HTTPS. Die Dienste erhalten technisch IP-Adresse, Abrufzeit, angeforderte Ressource und den User-Agent PlanetaryLens/0.9 (Android; direct provider media). Die Anfragen enthalten keine Werbe-, Installations- oder Kontokennung, GPS-Position, Suchtexte oder Merkliste. Die angeforderte Ressource kann erkennen lassen, welchen Inhalt du ansiehst. Die App setzt nicht absichtlich Cookies und sendet keine Browser-Cookies. PlanetaryLens enthält keine Werbung, kein Konto, keine Analyse- oder Crash-SDKs und verkauft keine Daten.

Lokale Speicherung, Aufbewahrung und Löschung

Die Merkliste speichert Katalog-IDs im privaten App-Speicher. Suche, Kartenauswahl und aktuelle Ansicht werden lokal verarbeitet; Android kann den Bildschirmzustand zur Wiederherstellung vorhalten. Die primäre Gerätesprache wird lokal gelesen: Bei Deutsch erscheint Deutsch, bei jeder anderen Sprache Englisch. Diese Einstellung wird nicht als Nutzerpräferenz übertragen.

Falls eine Quellen-Manifest-URL konfiguriert ist, wird das zuletzt erfolgreich geladene Manifest lokal gespeichert. Es enthält Quellen-IDs, Betreibernamen und öffentliche Hinweise, keine Nutzerkennungen. Eine erfolgreiche Aktualisierung ersetzt den bisherigen Stand. In PlanetaryLens 0.9 ist keine solche URL konfiguriert; die Datei wird daher weder angefragt noch gespeichert.

Cloud-Backup und Geräteübertragungs-Backup der App sind deaktiviert. Bilder, Videopuffer und Messdaten liegen im Arbeitsspeicher; es gibt keinen dauerhaften Mediencache. Das Schließen einer Ansicht gibt ihre Medien frei; Android verwaltet die endgültige Speicherbereinigung.

Einzelne Einträge entfernst du über den Stern, die gesamte Merkliste unter „Über PlanetaryLens“. Alle lokalen Daten entfernst du über Android-Einstellungen → Apps → PlanetaryLens → Speicher → Daten löschen oder durch Deinstallation. Dies löscht keine Anbieterprotokolle. Es gibt kein PlanetaryLens-Konto und keine serverseitige PlanetaryLens-Nutzerdatenbank.

Quellensteuerung

Bei konfigurierter Manifest-URL lädt die App beim Wechsel in den Vordergrund und dort etwa alle 15 Minuten eine kleine HTTPS-Datei. Sie kann Quellen entfernen und Hinweise anzeigen, aber keinen ausführbaren Code laden oder Quellen hinzufügen. Der Hoster erhielte die oben beschriebenen Verbindungsdaten. Ohne Netz gälte die letzte gültige Datei; eine sofortige Entfernung auf einem offline betriebenen Gerät ist nicht garantiert. PlanetaryLens 0.9 konfiguriert diese URL nicht.

Diese Erklärung ist in der App offline lesbar. Das Öffnen der öffentlichen Webfassung kontaktiert GitHub Pages über deinen Browser.
